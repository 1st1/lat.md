# Docs

The [[src/app.dart#NameMapper]] alias maps names, while [[src/app.dart#defaultName]], [[src/app.dart#fallbackName]], and [[src/app.dart#greetingCount]] store top-level values.

Call [[src/app.dart#greet]] directly or construct [[src/app.dart#Greeter]] with [[src/app.dart#Greeter#Greeter]] or [[src/app.dart#Greeter#named]].

The class exposes [[src/app.dart#Greeter#prefix]], [[src/app.dart#Greeter#separator]], [[src/app.dart#Greeter#greet]], [[src/app.dart#Greeter#label]], and [[src/app.dart#Greeter#operator ==]].

[[src/app.dart#Greeting]] contributes [[src/app.dart#Greeting#wave]], and [[src/app.dart#GreeterFormatting]] contributes [[src/app.dart#GreeterFormatting#shout]].

The [[src/app.dart#Color]] enum contains [[src/app.dart#Color#red]] and exposes [[src/app.dart#Color#label]].

The [[src/app.dart#UserId]] extension type exposes [[src/app.dart#UserId#value]] and [[src/app.dart#UserId#format]].

The [[src/app.dart#DotShorthand]] class uses Dart 3.7 dot shorthand inside [[src/app.dart#DotShorthand#pick]].
